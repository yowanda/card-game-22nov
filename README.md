Tidecaller Duel — a complete, original card battler that plays offline in a desktop browser from its own files. You are the Tidecaller, duelling Kess the Ember Warden: summon creatures of Flame, Tide, Leaf and Stone, chain their elemental advantages (Flame beats Leaf, Leaf beats Tide, Tide beats Stone, Stone beats Flame), cast surge and mend spells, and reduce the rival hero to 0 life before yours falls. Keyboard and mouse play, animated dealing, an AI opponent that reads the board, and title, win and loss screens.

## Run it

```sh
cd game && python3 -m http.server 8000
```

Then open http://localhost:8000 in desktop Chrome. No network, no build step, no install.
